# Preety Polish

Website for Preety Polish, a nail and beauty salon in Niš. Visitors can browse services, read about the salon, and find contact details to book an appointment.

## Pages

- **Home** (`/`) — introduction, highlights, and a preview of services
- **Services** (`/usluge`) — manicure, permanent makeup, and education, with a detail page for each
- **About** (`/o-nama`) — the salon story and vision
- **Contact** (`/kontakt`) — phone, email, address, and social links

## Technologies

- **React** — component-based interface
- **React Router** — page navigation
- **Vite** — development server and production build
- **Tailwind CSS** — layout and styling
- **Framer Motion** — page transitions

## Getting started

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local address shown in the terminal (usually `http://localhost:5173`).

## Build

Create a production build:

```bash
npm run build
```

Preview that build locally:

```bash
npm run preview
```
